#1 hidden_layer_activations annotated as int — should be list[str] High
sdevpy/machinelearning/pytorch/topology.py · line 41

Why it's bad: The signature of the new compose_model reads: 

def compose_model(n_inputs: int, n_outputs: int, hidden_layer_activations: int, neurons: int, ...):

The body immediately iterates over it with for activation_name in hidden_layer_activations, proving it must be a sequence of strings. The wrong annotation will cause every type-checker (mypy, pyright, the IDE) to flag a valid call like compose_model(7, 1, ['softplus', 'softplus', 'softplus'], 16) as a type error, and it actively misleads anyone reading the signature.

Fix:

def compose_model(n_inputs: int, n_outputs: int, hidden_layer_activations: int, ...
def compose_model(n_inputs: int, n_outputs: int, hidden_layer_activations: list[str], ...

#6 settings.WORKFOLDER is a hardcoded Windows-only path committed to the repo Medium
sdevpy/settings.py · line 9

Why it's bad: WORKFOLDER = r"C:\temp\sdevpy" is a machine-specific Windows absolute path checked into source control. Any contributor on Linux or macOS, or a Windows user with a different layout, will silently be directed to a non-existent path. Scripts that consume it (e.g. stovolgen.py, see issue #7) will fail at runtime with a FileNotFoundError that looks like a bug rather than a missing configuration.

Fix:

import os
from pathlib import Path
WORKFOLDER = r"C:\temp\sdevpy"
WORKFOLDER = Path(os.environ.get('SDEVPY_DATA', Path.home() / 'sdevpy'))

#9 _get_activation constructs all 19 activation modules on every call Low
sdevpy/machinelearning/pytorch/topology.py · lines 7–33

Why it's bad: The activations dict is rebuilt from scratch inside the function body on every call, constructing all 19 nn.Module instances even though only one is returned and used. For a 3-layer model, compose_model allocates 57 modules and discards 54. The idiomatic pattern is a module-level dict of class references (factories) that instantiate only what is requested: 

# Current — 19 modules constructed, 18 discarded per call:
def _get_activation(name: str) -> nn.Module:
    activations = {'relu': nn.ReLU(), 'tanh': nn.Tanh(), ...}
    return activations[name]

# Fix — 1 module constructed per call:
_ACTIVATION_FACTORIES: dict[str, type[nn.Module]] = {
    'relu': nn.ReLU, 'tanh': nn.Tanh, 'sigmoid': nn.Sigmoid, ...
}
def _get_activation(name: str) -> nn.Module:
    if name not in _ACTIVATION_FACTORIES:
        raise ValueError(f"Unsupported activation: {name}")
    return _ACTIVATION_FACTORIES[name]()

Moving _ACTIVATION_FACTORIES to module level also makes it easy to enumerate all supported activations without calling the function.
