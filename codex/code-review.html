#1Valid shifted-lognormal targets are silently discardedHigh
sdevpy/volatility/impliedvol/optionsurface.py:64–80

Evidence: keep_positive hard-codes shift = 0 rather than using target.market_shift. A −1% forward and −0.5% strike with a +3% shift are valid in shifted space but removed; whole expiries can disappear because skipping is the default.

Impact: negative-rate calibration baskets become incomplete and expiry alignment can change silently.

Proposed replacement:

shift = 0
f = target.forward + shift
k = target.strike + shift
shift = (target.market_shift
         if target.quote_type == OptionQuoteType.ShiftedLogNormalVol else 0.0)
f = target.forward + shift
k = target.strike + shift

Add a regression test using negative raw values that become positive after shifting.

fig, axs = plt.subplots(num_rows, num_cols, squeeze=False, layout="constrained")

#4Numerical routines overwrite NumPy’s process-wide error policyMedium
sdevpy/volatility/impliedvol/models/sabr.py:27–35; sdevpy/volatility/mlsurfacegen/smilegenerator.py:109–132

Evidence: SABR changes invalid to ignore and then hard-codes warn; to_nvol similarly changes divide from raise to warn. Neither restores the caller’s prior setting, and exceptions can skip restoration.

Impact: these calls alter unrelated numerical behavior and may suppress later invalid-value warnings.

Proposed replacement:

np.seterr(invalid='ignore')
correction = np.where(...)
np.seterr(invalid='warn')
with np.errstate(invalid="ignore"):
    correction = np.where(...)

np.seterr(divide='raise')
# conversion loop
np.seterr(divide='warn')
with np.errstate(divide="raise"):
    # conversion loop
#5Seeded SABR generation is non-reproducible when noise is enabledMedium
sdevpy/volatility/mlsurfacegen/smilegenerator.py:17–24; sdevpy/volatility/mlsurfacegen/sabrgenerator.py:230–238

Evidence: the generator owns seeded self.rng, but noise selection and magnitude use global np.random.rand().

Impact: identical seeds produce different datasets, weakening model comparison and reproducible debugging.

Proposed replacement:

rand = np.random.rand()
noise = (np.random.rand() - 0.5) * rel_noise / 0.5
rand = self.rng.rand()
noise = (self.rng.rand() - 0.5) * rel_noise / 0.5

#7Monte Carlo pricing always prints timing linesLow
sdevpy/montecarlo/mcpricer.py:53–60, 183–186; sdevpy/utilities/timer.py:25–28

Evidence: price_book unconditionally calls mc.print_timers(), which uses built-in print.

Impact: callers cannot control output through logging; notebooks, services, and calibration runs accumulate noise.

Proposed replacement:

mc_price = mc.pv(book)
mc.print_timers()
mc_price = mc.pv(book)
if kwargs.get("print_timers", False):
    mc.print_timers()

Alternatively emit timings through a module logger at debug level.

#8One checkpoint loader lacks the weights-only restrictionLow
sdevpy/llms/gpt/gpt.py:170–184

Evidence: torch.load(weight_file, map_location=device) accepts full pickle payloads; the other repository loader in machinelearning/pytorch/learningmodel.py already passes weights_only=True.

Impact: with configurations permitting unrestricted pickle, an untrusted checkpoint can execute code.

Proposed replacement:

checkpoint = torch.load(weight_file, map_location=device)
checkpoint = torch.load(weight_file, map_location=device, weights_only=True)
#9Parallel FX calibration drops worker traceback contextLow
sdevpy/volatility/fx/fx_calib_batch.py:40–51

Evidence: the broad worker exception handler logs only the exception string and stores None.

Impact: long multiprocess batch failures are hard to diagnose, while callers must remember values can be null.

Proposed replacement:

except Exception as exc:
    log.error(f"Calibration failed for {pair} on {date}: {exc}")
    results[(pair, date)] = None
except Exception:
    log.exception("Calibration failed for %s on %s", pair, date)
    results[(pair, date)] = None

Also return or raise a failed-key summary so partial success is explicit.
